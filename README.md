# C programming exercises

C programming exercises covering control flow, arrays, strings, functions, and introductory problem solving.

## Project scope

Each C source file is a separate exercise. Build one example at a time with a C compiler; generated IDE files are not required to understand the source.

## Compile an exercise

For example, with GCC:

```sh
gcc '2d array addition/src/2d array addition.c' -o /tmp/c-exercise
/tmp/c-exercise
```
